# TradingAI Constitution

Version : 1.0
Status  : Active

このフォルダはTradingAIプロジェクトにおける最高位設計文書を管理します。

TradingAIの設計・レビュー・仕様書・作業指示書は、
本フォルダの思想および文書体系を最優先として扱います。

ChatGPT・OpenCode・Developer・Reviewer は、
本フォルダを設計判断の基準として扱うこと。

---

## TradingAI Document Hierarchy

1. Constitution
2. ADR (Architecture Decision Records)
3. Master Specification
4. Feature Specification
5. Task Instruction
6. Implementation
7. Runtime Result

---

## Governance Rules

設計判断に迷った場合は、この優先順位に従うこと。

下位文書が上位文書と矛盾する場合は、
独自判断で修正せず、設計差異として報告すること。

Constitution・ADR・Master Specificationの更新が必要と判断した場合は、
変更提案として報告し、正式な設計判断を経て更新すること。

このREADMEはTradingAIプロジェクトの入口文書であり、
詳細は各Constitution文書を参照すること。
