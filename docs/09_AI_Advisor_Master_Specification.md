# AI Advisor Master Specification v1.0

## 1. Purpose

AI Advisor is the central intelligent assistant for the TradingAI platform.

Its role is to provide a single location for:

- TradingAI consultation
- Architecture guidance
- Market Intelligence consultation
- Money Management consultation
- Replay consultation
- Runtime diagnosis
- Future AI integration

The first implementation is Platform Ready only.
No AI API integration is included in this version.
